Rules the interface obeys

Four constraints, applied on every screen

Colour never means good or bad

Crimson marks a presumptive positive, teal a negative, amber an abstention. None of them is a success state. An interface that celebrates a positive is an interface that pressures the operator toward one.

Nothing is hidden because it is unflattering

A location disagreement, a weak attestation, a wide prediction set — each is shown on the screen where it occurs and written into the record. The defence sees what the prosecution sees.

The word presumptive is never off-screen

It sits in the result verdict, in the sealed record, on the certificate, and in the export. There is no screen state in which a user can forget what class of claim this is.

Measured quantities are set in mono

Anything the verifier can recompute — hashes, ΔE, Lab triples, coordinates, α — is typeset in IBM Plex Mono. Prose is Archivo. The typeface tells you whether a number is evidence.

Blank fields stay blank

The §63 certificate ships with the human signature lines empty and marked in amber. The app computes the hash; it does not sign on anyone's behalf.

Every gate can be overridden, and the override is recorded

Field conditions are not negotiable with software. The quality gate can be passed under protest — and the protest becomes part of the signed record.
